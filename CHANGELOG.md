## [0.1.0] - 2026-10-07
### Added
- **System, Camera and Paint are main menus of the camera**: each has its own collapsible heading with its sub-groups below (indented), like Paint had before. The sub-group "Rec Format (companion values)" moved next to the other System sub-groups.
- **A.SHT Limit, Detect Window, Auto ND Filter** (FS7M2 round 48, scene + ALL): A.SHT Limit is scene `00084` / ALL `00225` (the value is the denominator, standard 1/2000; it used to be shown as "ISO / EI value", which was wrong), Detect Window 1 to 6 (`00088` / `00267`), Auto ND Filter is field 4 of the ND value (`00097` / `00280`). Auto Shutter is `00090` / `00269` (round 49), Clip High Light `00087` / `00266` (round 50) and, by elimination, Detect Window Indication `00089` / `00268` (stored inverted: 0 = On). Auto Exposure is complete.
- **Auto Exposure AGC and AGC Limit** (FS7M2 round 47, scene + ALL): AGC On/Off (scene `00079` / ALL `00235`; the earlier id map entry `00079` = `00219` was wrong; ALL `00232` field 4 follows it), AGC Limit per dynamic range (`00161`-`00163` / `00456`-`00458`, position in the manual's six-entry list, default 4), greyed out while AGC is Off. Mode Spotlight = 3 confirmed, Level 0 writes `1, 0` again.
- **Auto Exposure Level, Speed and Mode** (FS7M2 rounds 45 and 46; ALL `00221` / `00222` / `00265`, scene `00081` / `00082` / `00086`): Level -2.0 to +2.0 in steps of 0.25 (file: level x 100 in the second field, the first field becomes 100), Speed ±99, Mode Standard = 1 / Backlight = 2 (Spotlight = 3 assumed). New sub-group "Camera › Auto Exposure".
- **ISO/Gain/EI in SCENE files:** the manual lists ISO/Gain/EI, ND Filter and Auto Exposure as saved in both file types; the scene counterparts (`00123`-`00135`) show the same dropdowns now.
- **Gamma User select in SCENE files:** scene `00121` = ALL `00191` (found from the first scene + ALL pair since round 17: the only unmatched change on both sides); the Gamma Category row offers the User select in scene files, too.
- **ND Filter presets** <1> <2> <3> (FS7M2 round 43; ALL `00280`, scene `00097`): dropdowns 1/4 to 1/128 (the value is the denominator); all three presets are confirmed (rounds 43 and 44). Shown for the six-field shape of the FS7M2 only (the Mk1 value stays a text field). The previously unknown scene ID `00097` is therefore known now. New sub-group "Camera › ND Filter".
- **Camera > ISO/Gain/EI** (FS7M2 rounds 40-42, ALL files): Mode ISO / dB (`00389`), the dB gain per switch position <L> <M> <H> (`00399`-`00401`, -3 to 18 dB in 3 dB steps, index = dB / 3 + 1) and the ISO index per dynamic range (460% `00390`-`00392`, 800% `00393`-`00395`, 1300% `00396`-`00398`; position in the manual's ISO list). The 800% triplet is confirmed, the other two ranges follow from it (hypothesis); 18 dB and -3 dB are assumed. New sub-group "Camera › ISO/Gain/EI".
- Fix: the Gamma Category row now gets the yellow "changed" frame when only its select changes (e.g. User 5 -> User 1 changes only the select value, not the category flags); it also disappears again when the loaded value is restored.
- **Gamma User select** confirmed (FS7M2 rounds 38 and 39): User 1 = 0, User 5 = 4 (User 4 = 3 was known); User 2 and 3 follow from the order. Switching to User also switched Knee Setting and Black Gamma Setting off, as the app does since the STD rule.
- **Master Black Gamma** negative values confirmed (FS7M2 round 37): -7 is stored as -7, like +5 as 5.
- **Black Gamma Range** complete (FS7M2 rounds 35 and 36): High = 1 (the camera default, also the value in all older files), Mid = 2, Low = 3. The earlier assumption "1 = Mid" was wrong; the dropdown now offers all three.
- **Auto Knee** also writes ALL `00232` field 6 (1 = Off, 0 = On; FS7M2 rounds 31-33), like the camera does.
- **Knee Setting and Black Gamma Setting follow the STD category** (FS7M2 rounds 25-30): leaving STD (HG, User, S-Log2, S-Log3) switches both off like the camera does, and choosing STD again brings back the state STD had (in one undo step). Gamma Category dropdown option `remember` in the databases. Preset Matrix does not change with the category (rounds 24-27).
- **Master Black as wheel clicks** (FS7M2 rounds 18-23, measured click by click): the field counts wheel clicks (41.351 per click; buttons ±1 click and ±8 = one whole menu step), next to it "Camera menu shows: n" (clicks / 8, cut towards zero, so -7..+7 clicks show 0) and an info symbol that explains it. Replaces the unscaled raw field; the Mk1 menu raster is not measured yet, so the hint is shown for the FS7M2 only. Range ±99 menu steps (792 clicks) is an assumption.
- Fix: switching to "System" built the window in the colours of the previous mode (dark menu bar text on a dark bar after Day -> System): the system mode is detected at once now, and the window follows when the system switches between light and dark while "System" is selected.
- **Day / night mode:** View > Appearance > System / Day / Night (default Night); the choice is saved in the settings file. The window is rebuilt on a change, because the plain tk widgets and menus do not follow by themselves.
- **Jump buttons** ("Go to": Video, Audio, Miscellaneous, Unknown) below the filter row open their block and scroll to its header; the block headers and the buttons carry small Unicode icons (no image files). Buttons of blocks the shown file does not have (Audio and Miscellaneous in SCENE files) are greyed out and come back with ALL.
- **Clearer layout:** every sub-group sits in its own rounded card with a slightly different fill; dark, thick lines separate the main blocks (Video, Audio, ...) and the Paint category, light, thin lines separate the sub-groups.
- **Expand all / Collapse all** (View menu, Ctrl+Shift+Down / Ctrl+Shift+Up, and two buttons next to the filter): opens or closes every block, category and sub-group; expanding builds the block of unknown parameters.
- All sub-groups of the camera's Paint menu sit under one collapsible heading "Paint" (the sub-group headings are indented and show the part after "Paint ›"); a filter keeps matches visible while Paint is collapsed. Offset White now follows Matrix in the menu order.
- **Offset White** <A> and <B> (FS7M2 rounds 14 and 15): On/Off flags (scene `00149` / ALL `00501`), Warm Cool / Balance <A> (`00150` / `00502`) and <B> (`00154` / `00508`) in the new sub-group "Paint › Offset White", scale 330.16 per step, shown cut towards zero like the camera (new `trunc` option of step fields); locked with their On/Off flag. ID map extended. FS7M2 round 16: Warm Cool / Balance <ATW> (`00152` / `00505`) and White Switch<B> Memory / ATW (`00118` / `00312`); the <ATW> flag (third field of `00149`) was confirmed in round 17 and locks the <ATW> values; Offset White is complete.
- **Black Gamma** (FS7M2 round 13): setting (scene `00016` / ALL `00037`), range (`00015` / `00036`; Low = 3 confirmed, Mid = 1 assumed, High not offered) and Master Black Gamma (`00011` / `00032`, -99..+99 stored as the step itself) in the new sub-group "Paint › Black Gamma", locked with Off, with a gamma category other than STD, and against Knee Saturation (and the other way round). Group locks can now name a sub-group exactly (`subgroup`), so the Black lock no longer reaches Black Gamma.
- **Knee Saturation** (FS7M2 round 12): setting (scene `00061` / ALL `00109`, check box) and level (`00059` / `00107`, locked while the setting is Off, with the Knee and category locks). Fix: when a file was opened in place, the value of a row that the new file locks (greyed out) stayed at the old file's value; every row is now unlocked before its text is set and locked again afterwards.
- **Knee** (FS7M2 round 11): Knee Setting (scene `00060` / ALL `00108`, check box), Auto Knee (`00056` / `00104`), Knee Point 75 to 109 % (`00057` / `00105`, file value x 1000) and Knee Slope (`00058` / `00106`) with locks (Knee Off, gamma category other than STD); the ID map entries for these four IDs are confirmed by the real file pair.
